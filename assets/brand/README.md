# Identidade visual — CAR KING Auto Sales

A logo oficial está em `carking-logo.png` (o app usa uma versão recortada e otimizada em `app/public/logo.webp`).

Arquivos previstos:

| Arquivo | Uso |
|---|---|
| `carking-logo.png` | Logo completa (fundo preto) — tela de login, cabeçalho, relatórios PDF |
| `carking-logo-transparent.png` | Logo sem fundo — para usar sobre outras cores |
| `carking-icon-1024.png` | Ícone quadrado (coroa) — ícone do app iOS/Android e favicon |

A logo é um esportivo em linhas prateadas cromadas com uma coroa dourada, o texto **CAR** em prata,
**KING** em dourado e **AUTO SALES** em branco espaçado, sobre fundo preto.

## Paleta do app (tema claro)

O app usa fundo claro e neutro; o dourado aparece só como detalhe da marca.

| Token | Cor | Uso |
|---|---|---|
| `bg` | `#F6F6F4` | Fundo |
| `surface` | `#FFFFFF` | Cartões |
| `ink` | `#1B1C1E` | Texto e botões principais |
| `text-2` | `#6A6C70` | Rótulos |
| `border` | `#E4E4E0` | Bordas |
| `gold` | `#A6801F` | Detalhes da marca (menu ativo, logo) |
| `success` / `warning` / `error` | `#1E7F4F` / `#A35F00` / `#C2353A` | Lucro, aviso, prejuízo |

## Paleta original da logo (fundo preto)

| Token | Cor | Uso |
|---|---|---|
| `primary` | `#D4AF37` (dourado) | Botões principais, destaques, valores de lucro |
| `primaryLight` | `#F2D16B` | Hover, gradiente dourado |
| `primaryDark` | `#A8841F` | Botão pressionado, bordas |
| `secondary` | `#C9CDD2` (prata cromada) | Ícones, textos secundários sobre fundo escuro |
| `background` | `#0B0B0C` (preto) | Fundo do app (tema escuro, padrão) |
| `surface` | `#17181A` | Cartões e painéis |
| `surfaceAlt` | `#222326` | Campos de formulário, linhas de tabela |
| `textPrimary` | `#FFFFFF` | Texto principal |
| `textSecondary` | `#A7ABB2` | Rótulos e legendas |
| `success` | `#2EB872` | Lucro, dentro do orçamento, operação viável |
| `warning` | `#F0A92E` | Orçamento estourado (aviso), documento pendente |
| `error` | `#E5484D` | Prejuízo, estouro crítico, lance acima do limite |

Tema claro (opcional): fundo `#F6F6F4`, superfície `#FFFFFF`, texto `#111111`, mantendo dourado e prata.

## Tipografia sugerida

- Títulos e números grandes: **Montserrat** (SemiBold/Bold, itálico nos títulos combina com a logo)
- Textos e tabelas: **Inter**
- Valores monetários: Inter com algarismos tabulares, formato `$12,000.00`
